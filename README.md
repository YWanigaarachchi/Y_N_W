# YNW Software Solutions

Futuristic, highly interactive "Zero-G" digital agency portfolio built with raw vanilla CSS glassmorphism, Three.js 3D WebGL animations, and seamless WhatsApp inquiry/order pop-out modals.

---

## 🌟 Visual & Interactive Features

- **Three.js Interactive 3D AI Core**: A floating, wireframe sphere with orbit ring telemetry that reacts to mouse movements and floats dynamically in space.
- **Background Drifting Particles**: Real-time canvas particle starfield creating a weightless atmosphere.
- **Futuristic Glassmorphism**: Frosty panels, neon cyan borders, and deep indigo glow animations.
- **Custom Interactive Neon Cursor**: Dual-element floating dot and cursor follower that auto-hides over forms and interactive inputs.
- **Ultra-Smooth Scroll Up**: Custom `requestAnimationFrame` navigation utilizing `easeInOutCubic(t)` easing curve for 60fps/120fps smooth transitions.
- **Pop-Out Order Modals**: Dynamic WhatsApp lead-capture overlay form allowing users to submit contact details and inquiries directly to specific phone lines.
- **100% Mobile Responsive Layout**: Complete cross-device optimization supporting iPhone/Android viewports, scrollable modal forms, and a left-aligned workflow timeline.

## 📂 Web Application Architecture

- `index.html` — Zero-G agency landing hero and core business pillars.
- `about.html` — Professional developer profile linked directly to GitHub avatar, credentials, and milestones.
- `project.html` — Pure project gallery displaying completed public GitHub repositories:
  - **Siyala_HMS1** (`https://github.com/YWanigaarachchi/Siyala_HMS1`)
  - **lankarest-hms** (`https://github.com/YWanigaarachchi/lankarest-hms`)
  - **Resortify-hms** (`https://github.com/YWanigaarachchi/Resortify-hms`)
  - **athithi-hms** (`https://github.com/YWanigaarachchi/athithi-hms`)
- `process.html` — Pulsing laser timeline mapping client-agency milestones.
- `contact.html` — Interactive developer terminal console and direct WhatsApp hotline cards.
- `style.css` — Custom utility typography, keyframes, and mobile layout media queries.
- `script.js` — Native JS animation handlers, modal builders, and particle scene controllers.

## ⚙️ Quick Start & Local Preview

To launch the website locally:

1. Clone or download this repository.
2. Open your terminal in the project directory.
3. Start a local server:
   ```bash
   # Using Python 3
   python -m http.server 8080
   ```
4. Open your browser and navigate to `http://localhost:8080`.
